# Пепельные земли: план на двоих

План прохождения Пепельных земель (Ashlands) в Valheim для кооператива вдвоём: фазы с чек-листами, броня, еда, зелья, оружие, враги, обугленные крепости и тактика против босса Фейдера.

**Открыть онлайн:** https://kvtvsi.github.io/valheim-ashlands-plan/

## Как открыть на Windows без интернета

1. Нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив.
2. Дважды щёлкните `open-plan.bat` (или сам `index.html`). План откроется в браузере по умолчанию.

Без интернета страница работает целиком, только шрифты заменятся системными (Palatino Linotype, Segoe UI, Consolas).

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Вся страница: HTML, стили и скрипт в одном файле |
| `open-plan.bat` | Открывает `index.html` в браузере по умолчанию |

Галочки в чек-листах сохраняются в `localStorage` вашего браузера, поэтому у каждого игрока свой прогресс. Кнопка «Сбросить все галочки» очищает его.

## Источники

Цифры, рецепты и сопротивления взяты из [Valheim Wiki](https://valheim.fandom.com/wiki/Ashlands). Тактика сведена из вики и гайдов, ссылки есть внизу страницы. Если после патча что-то не совпадает с игрой, верьте игре.
